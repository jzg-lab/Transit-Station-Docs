Cursor 中转 API 配置

本页只保留参考教程中“中转 API”之后的配置流程。Cursor 的下载、入门介绍和快捷键不放在这里；接入时直接进入 Cursor 的模型设置，按 OpenAI 兼容接口填写词元.fast 信息。

官网 cursor.com 控制台 词元.fast API 密钥 参考 Cursor 中转 API 配置

一、准备词元.fast API Key

打开 词元.fast API 密钥页面，点击左侧 API 密钥，再点击右上角 创建密钥。创建成功后复制你的专属 Key，后续粘贴到 Cursor 的 API Key 输入框。

平台里的 Key 通常以 sk- 开头。复制时注意不要带空格，也不要把截图里的示例 Key 当成真实 Key 使用。

二、填写 Cursor OpenAI API 配置

  1. 打开 Cursor 设置，进入模型或 API 配置区域。
  2. 找到 OpenAI API Key 或同名的自定义 OpenAI 配置。
  3. 在 Base URL / API Base URL 中填写 https://ciyuan.fast/v1。
  4. 在 API Key 中粘贴刚刚从词元.fast 创建并复制的令牌。
  5. 点击 Verify 验证，成功后打开对应开关。
Base URL: https://ciyuan.fast/v1
API Key: 粘贴你在词元.fast 创建的 sk-... 密钥

三、添加并选择模型

验证通过后，在 Cursor 的模型列表里添加词元.fast 控制台可用的模型 ID。参考教程里使用的是 Cursor 专属模型名；这里不要照抄旧中转站的域名或模型名，优先使用你在词元.fast 控制台已开通的模型。

如果你正在做代码编辑任务，可以先选择一个代码能力强、延迟稳定的模型。添加后回到聊天或 Composer 面板，发送一句简单请求验证是否能正常回复。

四、常见问题

  • Verify 失败：先确认 Base URL 是否为 https://ciyuan.fast/v1，再检查 Key 是否完整。
  • 模型不可用：模型 ID 必须和词元.fast 控制台可用名称一致。
  • 仍然走 Cursor 默认额度：确认 OpenAI API 配置开关已经打开，并在模型选择处选中了你添加的模型。
