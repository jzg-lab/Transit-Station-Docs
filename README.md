# 词元.fast 文档中转站

这是词元.fast 的 AI 应用接入文档站，用来把常见客户端、编程助手、机器人平台、阅读工具和部署工具的接入教程集中到一个入口。

## 本地运行

```bash
npm run serve
```

默认使用 Python 静态文件服务器，启动后访问：

```text
http://127.0.0.1:8080/
```

## 测试

```bash
npm test
```

测试会检查首页内容、教程页生成结果、品牌替换、截图引用、交互脚本和基础安全硬化点。

## 文件结构

- `index.html`：首页结构，包含首屏入口和应用接入地图容器。
- `app.js`：首页数据、卡片渲染、搜索筛选、滚轮分页切换逻辑。
- `styles.css`：全站样式、首页过渡动画、教程页样式。
- `docs.js`：教程页轻量交互，包括图片放大、复制按钮和目录生成。
- `docs/`：已发布的独立教程 HTML 页面。
- `images/`：教程截图和站点图片资源。
- `scripts/build-doc-pages.js`：从首页数据/模板生成独立教程页的脚本。
- `site.test.js`：Node.js 测试用例。

## 交互说明

首页采用两段式体验：

1. 第一页是品牌和快速查找入口。
2. 第二页是应用接入地图。

滚轮切页不是直接触发，而是先允许页面自然滚动；到当前页面边界后继续滚动，才会累积阈值并切换页面。这样可以避免误触，也更接近真实应用的页面切换手感。

## 开发原则

- 尽量保持静态站点简单可部署，不引入前端框架。
- 新增教程优先复用现有卡片、资源链接和截图结构。
- 涉及用户可见交互时，需要同步更新 `site.test.js`。
- 外链使用 `target="_blank"` 时必须带 `rel="noreferrer"`。
